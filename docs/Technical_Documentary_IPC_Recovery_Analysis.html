Reconciliation Methodology

The reconciliation engine transition from Direct IPC Matching to Composite Identity Mapping to resolve the identification gap.

Criteria Logic Implementation Confidence
School ID Exact String/Integer match on DepEd identifiers High
Funding Year Fiscal Year synchronization (2015-2024 range) High
Category Fuzzy mapping: "New Construction" → "NC" Medium
Budget (ABC) Numerical match with $1.00 tolerance (Rounding buffer) High

Algorithmic Logic (SQL Implementation)

The following query was utilized to identify the 9,245 recovery candidates without creating collisions:

WITH recovery_matches AS ( SELECT e.project_id, i.ipc as correct_ipc FROM engineer_form e JOIN import_beff_projects i ON e.school_id::text = i.school_id::text AND e.funding_year::text = i.funding_year::text AND (i.project_category IN ('NC', 'New Construction')) AND ROUND(e.approved_budget::numeric, 0) = ROUND(i.approved_budget::numeric, 0) WHERE e.project_category = 'New Construction' AND NOT EXISTS (SELECT 1 FROM import_beff_projects i2 WHERE i2.ipc = e.ipc) ) UPDATE engineer_form SET ipc = recovery_matches.correct_ipc ...
