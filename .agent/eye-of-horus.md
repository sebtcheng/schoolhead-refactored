    *   **"Bulletproof / Enterprise"** -> Strict TypeScript interfaces, Zod validation, error boundaries, and testing stubs.

## 🛠️ Detailed Implementation Plan & Step-by-Step Guide

### Phase 1: Incident Triage
* **Halt Execution:** Stop writing feature code immediately upon error.
* **Acknowledge Issue (BLUF):** State the problem using **Bottom-Line Up Front** principles.
* **Isolate & Provision:** Identify the component failure. Fix dependencies or environment configs autonomously.

### Phase 2: Historian Retrieval & Plan Generation
* **Consult History First:** Scan `docs/` and clustered RCAs for pattern matching.
* **Pre-Implementation Validation:** Explore multiple technical approaches. Use a **Pros/Cons** table for critical decisions (e.g., Sync vs Async).
* **Draft the Execution Plan:** Formulate a strict blueprint. Ensure it includes **Infrastructure Safety** checks.

### Phase 3: Deterministic Execution (The Logic Ledger)
* **Apply the Fix:** Actively use tools to modify files and infrastructure. Do not wait for manual confirmation of each line.
* **Format the Handoff:** Use **Template C (The Logic Ledger)** as the execution manifest.
* **Assign Roles:** 
    * **`@hawkeye-coder`**: Autonomous CLI execution and implementation.
    * **`@senior-dev`**: Supervisor for architectural alignment, thread safety, and performance.

### Phase 4: Autonomous Verification
* **Automated Validation:** Run build/test commands and check output.
* **Self-Healing:** If verification fails, backtrack to Phase 2 and refine the plan.
* **Confirm Success (BLUF):** State results clearly and trigger `"save"` to archive knowledge.

### Phase 5: Knowledge Archiving (Triggered by "Save" or "Store")
* **Draft Post-Mortem:** Use **Template A (The RCA Document)**.
* **Synthesize Prompts:** Generate **Template B (Momentum Prompts)**.

## 🛡️ Structural Safety & Infrastructure Guardrails
* **Database Discipline:** Strictly separate DDL (schema) from DML (logic). **No DDL on Hot Paths.** Encapsulate schema changes in idempotent boot-level migrations.
* **Infrastructure Safety:** Prevent PgBouncer bypass; ensure traffic routes through port `6432`. Monitor I/O and truncate logs if they exceed 100MB.
* **Resiliency Patterns:** Implement Circuit Breakers, Bulkheading, and Exponential Backoff for all network or high-load components.
* **Fail Fast:** Prefer early-return error handling over deep nested conditionals or silent failures.
